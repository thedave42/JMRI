RailDriver Settings Window

The RailDriver Settings window provides centralised configuration for the RailDriver USB controller. Open it from Debug → RailDriver Settings, or by clicking the toolbar connection indicator.

The window has two tabs: Settings and Calibration.

Settings Tab

Controls the semi-realistic throttle engine parameters:

Ramp Timing

  • Enable semi-realistic throttle — master on/off toggle. A restart is recommended after changing.
  • Acceleration delay (ms/step) — milliseconds between speed steps when accelerating (default 300).
  • Deceleration delay (ms/step) — milliseconds between speed steps when decelerating (default 800).
  • Speed step increment — number of speed steps per ramp tick (default 1). Higher values produce a coarser, faster ramp.

Brakes

  • Independent brake steps — number of quantised brake notches (default 7).
  • Dynamic brake min speed step — speed step below which dynamic brake effect tapers to zero (default 8).

Air Brake

  • Line recharge (%/tick) — percentage of brake pipe recharged per air-repeater tick (default 20).
  • Air refresh rate (ms, 0=flat) — milliseconds between air-repeater ticks. Set to 0 for flat-mapping mode with no Westinghouse dynamics (default 2000).
  • Reservoir replenish (%/tick) — percentage of reservoir replenished per tick (default 5).

Load

  • Number of load steps — positions on the load slider (default 5). Step 0 is always “light engine” (1.0×).
  • Max load percentage (×100) — maximum load multiplier expressed as a percentage (default 1000 = 10×).

Decoder Integration

  • Decoder brake mode — NONE (default) or ESU. When ESU is selected, independent brake percentage is mapped to DCC function toggles at configurable thresholds.

Calibration Tab

Shows live HID byte values from each RailDriver axis and button, with visual calibration bars. Use this tab to verify that your RailDriver's physical controls map correctly to the expected value ranges.

Calibration data is per-machine and stored in the JMRI profile directory.

Save, Apply & Cancel

  • Save — validates both tabs, writes the calibration file to disk, reloads calibration into the running engine, and closes the window.
  • Apply — same as Save but keeps the window open.
  • Cancel — discards unsaved changes and closes the window.

Settings are pushed live to any attached semi-realistic engine on Save/Apply — no restart is needed for parameter changes (only for the enable/disable toggle).
