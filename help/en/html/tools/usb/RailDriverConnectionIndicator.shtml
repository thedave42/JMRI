RailDriver Connection Indicator

The RailDriver Connection Indicator is a small toolbar component (Jynstrument) that shows whether the RailDriver USB controller is currently connected to JMRI.

Visual States

  • Active (coloured icon) — the RailDriver device is connected and communicating.
  • Greyed icon — the RailDriver device is not detected or has been disconnected.

Interaction

  • Left-click — opens the RailDriver Settings window.
  • Right-click — shows a popup menu with a Settings… item that does the same.

Both click actions work regardless of the connection state (the indicator is never disabled).

Installation

The indicator is automatically installed on the throttle window toolbar when a RailDriver device is detected. No manual configuration is needed.

The indicator deregisters its listener when the throttle window is closed, preventing memory leaks.
