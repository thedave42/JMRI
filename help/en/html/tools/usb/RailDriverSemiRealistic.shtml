RailDriver Semi-Realistic Throttle

The semi-realistic throttle mode transforms the RailDriver USB desktop controller into a train-handling experience that mimics prototype locomotive behaviour. Instead of the throttle lever directly commanding a decoder speed, the lever sets a target speed step and the engine ramps the live speed toward that target one step at a time, modulated by brakes, air-line state, load, and direction.

This mode is inspired by the EngineDriver Android app's semi-realistic throttle and uses the same core algorithms.

Enabling Semi-Realistic Mode

Open the RailDriver Settings window (Debug → RailDriver Settings) and check Enable semi-realistic throttle. Click Save. A restart is recommended for the change to take full effect.

Speed Ramp

The ramp scheduler walks the decoder speed step toward the target at a configurable rate:

  • Acceleration delay — milliseconds between steps when accelerating (default 300 ms).
  • Deceleration delay — milliseconds between steps when decelerating/coasting (default 800 ms).
  • Speed step increment — number of speed steps per ramp tick (default 1, smoothest; higher values produce a coarser, faster ramp).

The minimum interval between actual decoder speed commands is a fixed 50 ms constant and is not user-configurable.

Brake System

The semi-realistic mode provides four brake sources, each contributing to total braking effort:

Independent Brake

Mapped to the RailDriver's independent brake lever. Applies locomotive-only braking as a non-linear curve (matching EngineDriver's getBrakeDecimalPcnt formula). The number of quantised brake notches is configurable (default 7).

Westinghouse Air Brake

Mapped to the RailDriver's automatic brake lever. Simulates a Westinghouse-style air brake system with three interacting state variables:

  • Brake pipe (air line) — 0–100%. Dropping the pipe applies brakes to the entire train. The pipe drops instantly on application and recharges gradually on release.
  • Main reservoir — 0–100%. Supplies air to recharge the brake pipe. Depletes during release cycles and replenishes slowly. When the reservoir is empty, the brake pipe cannot recharge (the brakes are “gone”).
  • Demanded line value — the target brake pipe pressure set by the lever position.

The air brake status is displayed in the Air Status Panel on the throttle window, showing brake pipe and reservoir gauges with colour-coded indicators.

Dynamic Brake

Activated by the RailDriver's dynamic brake zone. Contributes proportional braking that tapers linearly to zero below a configurable speed-step threshold (default 8), preventing a stall at very low speeds.

Bail-Off

When the bail-off button is held, all locomotive-side braking (independent, dynamic, and the locomotive's share of air braking) is released. Car-side air braking continues, so the train decelerates but the locomotive is free to pull against the consist. Releasing the bail-off button restores normal braking. On a light engine (load step 0), bail-off results in no braking at all.

Load Slider

The load slider on the Air Status Panel sets a multiplier that stretches both acceleration and braking delays, simulating the effect of train weight. The multiplier follows a quadratic curve:

The formula is: ((load² × (maxLoadPcnt − 100)) + 100) / 100, where load = step / numberOfLoadSteps. Both maxLoadPcnt (default 1000 = 10×) and numberOfLoadSteps (default 5) are configurable in the Settings window.

ESU Decoder Brake Passthrough

When decoder brake mode is set to ESU, the independent brake percentage is mapped to DCC function toggles at configurable thresholds. This lets ESU decoders with built-in brake sound effects synchronise their audio with the semi-realistic brake state.

Direction & E-Stop

The reverser lever sets the direction of travel. Changing direction while the locomotive is moving triggers a deferred direction change: the engine ramps to a stop first, then applies the new direction and resumes. Setting the reverser to Neutral is always allowed immediately.

The E-Stop button immediately cancels all ramp activity, commands speed step 0, and issues an emergency stop to the decoder.
